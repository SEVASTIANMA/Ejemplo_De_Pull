# *INVESTIGACIÓN: LENGUAJE DE PROGRAMACIÓN PYTHON*

## *1. ¿Qué es Python?*

-- Python es un lenguaje de programación de alto nivel, interpretado y de propósito general.

-- Se caracteriza por tener una sintaxis sencilla y fácil de leer, por lo que es utilizado tanto por principiantes como por programadores con experiencia.

## *2. ¿Para qué sirve Python?*
-- Python permite desarrollar aplicaciones y programas.

-- Se utiliza para crear páginas y aplicaciones web.

-- Permite trabajar con bases de datos.

-- Se utiliza en inteligencia artificial y aprendizaje automático.

-- Es utilizado para analizar y procesar datos.

-- Permite automatizar tareas repetitivas.

## *3. Características de Python*

-- Tiene una sintaxis sencilla.

-- Es fácil de leer y comprender.

-- Es multiplataforma.

-- Es un lenguaje de programación orientado a objetos.

-- Permite utilizar diferentes bibliotecas y módulos.

-- Cuenta con una gran comunidad de desarrolladores.

## *4. Variables en Python*

-- Las variables permiten almacenar información que puede utilizarse durante la ejecución de un programa.

-- En Python no es necesario indicar explícitamente el tipo de dato al crear una variable.
