# Variables en Programación

*¿Qué es una variable?*
-Una variable es un espacio en la memoria del computador que se utiliza para almacenar información. Su contenido puede cambiar durante la ejecución de un programa, por eso se llama

*¿Para qué sirven?*
-Las variables permiten guardar datos como números, textos o valores lógicos para que un programa pueda utilizarlos, modificarlos y realizar operaciones con ellos.

*Tipos de variables*
- Entero (int): almacena números enteros. Ejemplo: 25.
- Flotante (float): almacena números con decimales. Ejemplo: 3.14.
- Carácter (char): almacena un solo carácter. Ejemplo: 'A'.
- Cadena (string): almacena texto. Ejemplo: "Hola".
- Booleano (bool): almacena valores de verdadero o falso.
