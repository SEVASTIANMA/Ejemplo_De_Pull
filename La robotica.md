# La_robotica

  

Es una ciencia y tecnologia que une ramas como la mecanica, la electronica, la informatica y la inteligencia artificial. Su meta principal es diseñar, construir y programar maquinas y robots capaces de hacer tareas de forma automatica, imitar movimientos o ayudar al ser humano en trabajos dificiles o repetitivos. 

## 1. Programación de robots (como Arduino o bloques)

  La programación de robots mediante Arduino o bloques permite controlar motores, luces y sensores uniendo piezas visuales tipo rompecabezas o escribiendo código en **C++**. Facilita el salto lógico desde la robótica educativa inicial hasta proyectos avanzados de hardware libre 
## Herramientas de Programación por Bloques

  -  **mBlock:** Basado en Scratch, permite programar placas Arduino y ver el código equivalente.

  -  **PictoBlox:** Entorno visual intuitivo ideal para la educación y proyectos con sensores.

  -  **ArduinoBlocks:** Plataforma web en español muy popular para exprimir placas compatibles sin escribir código complejo.

  
  ## Transición a Código de Texto (Arduino IDE)

  -  **Estructura base:** Todo programa usa `setup()` para configurar pines y `loop()` para repetir instrucciones de movimiento de forma indefinida.

  -  **Lógica de control:** Se emplean condicionales (`if/else`) para que el robot tome decisiones al detectar obstáculos o líneas en el suelo
