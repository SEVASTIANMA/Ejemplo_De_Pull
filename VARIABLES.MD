## ¿Qué es una variable?

Una **variable** es un espacio en la memoria de un programa que se utiliza para almacenar un dato. Su valor puede cambiar durante la ejecución del programa.

Por ejemplo:
| Tipo     | Ejemplo    | Descripción                 |
| -------- | ---------- | --------------------------- |
| Entero   | `18`       | Números sin decimales       |
| Decimal  | `3.14`     | Números con decimales       |
| Texto    | `"Yofran"` | Palabras o cadenas de texto |
| Booleano | `True`     | Verdadero o falso           |
