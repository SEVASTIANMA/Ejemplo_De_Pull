# **INVESTIGACIÓN: PSEUDOCÓDIGO**

## **1. ¿Qué es el pseudocódigo?**

-- El pseudocódigo es una forma de representar un algoritmo utilizando un lenguaje sencillo y fácil de entender. No pertenece a un lenguaje de programación específico, sino que sirve como una guía para planificar la solución de un problema antes de escribir el código.
