# **INVESTIGACIÓN: PSEUDOCÓDIGO**

## **1. ¿Qué es el pseudocódigo?**

-- El pseudocódigo es una forma de representar un algoritmo utilizando un lenguaje sencillo y fácil de entender. No pertenece a un lenguaje de programación específico, sino que sirve como una guía para planificar la solución de un problema antes de escribir el código.

## **2. ¿Para qué sirve?**

-- Permite organizar las ideas antes de comenzar a programar.

-- Facilita la comprensión de los algoritmos.

-- Ayuda a detectar errores en la lógica de un programa.

-- Permite representar una solución sin preocuparse por la sintaxis de un lenguaje de programación.

-- Facilita la comunicación entre personas que están trabajando en el desarrollo de un programa.

## **3. Características del pseudocódigo**

-- Utiliza instrucciones sencillas y fáciles de comprender.

-- No tiene una sintaxis estricta como los lenguajes de programación.

-- Representa paso a paso la solución de un problema.

-- Puede utilizar estructuras de decisión y repetición.

-- Puede convertirse posteriormente en código de programación.

## **4. Estructura básica**

-- Un pseudocódigo generalmente comienza con el nombre del algoritmo.

-- Después se definen las variables necesarias.

-- Luego se escriben las instrucciones que debe ejecutar el programa.

-- Finalmente, se indica el final del algoritmo.

### **Ejemplo**

```text
Algoritmo Suma

    Definir numero1, numero2, resultado Como Entero

    Escribir "Ingrese el primer número:"
    Leer numero1

    Escribir "Ingrese el segundo número:"
    Leer numero2

    resultado = numero1 + numero2

    Escribir "El resultado es:", resultado

FinAlgoritmo
